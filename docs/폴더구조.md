# 폴더 구조 가이드

## 한눈에 보기
```
trabby/
├─ app/                    화면 "연결"만 (파일마다 한 줄). 하단 탭 설정은 _layout.tsx
├─ src/
│  ├─ features/            ★ 화면 코드는 탭(기능)별로 여기에
│  │  ├─ home/             홈 탭    : 노선도 지도 + 거북이 + 걸음 수 + 완주 화면
│  │  ├─ lines/            노선도 탭 : 노선 고르기 / 노선 상세 / 다음 노선 선택 시트
│  │  ├─ dex/              도감 탭  : 노선·캐릭터·뱃지 수집 현황
│  │  ├─ settings/         설정 탭  : 닉네임·알림·효과음·진동·테마·언어·FAQ
│  │  └─ onboarding/       첫 실행 안내 (처음 한 번만, 걸음 센서 권한 안내)
│  ├─ shared/              두 탭 이상이 같이 쓰는 부품 (거북이 그림)
│  ├─ store/               앱 상태와 저장 (걸음 수, 완주 기록, 설정)
│  ├─ lib/                 계산 (걸음 → 거리 → 지도 위 위치)
│  └─ data/                앱이 읽는 노선 데이터
│     └─ generated/        ⚠ 자동 생성 파일. 직접 수정 금지
├─ assets/
│  ├─ characters/          캐릭터 그림 (파일 이름 = 캐릭터 id + 상태, 투명 PNG)
│  ├─ sounds/              효과음 (arrive·goal·clear.wav)
│  └─ icon.png 등          앱 아이콘·시작 화면 (임시)
├─ data-source/            원본 데이터: 사람이 넣는 CSV + 수동 보완값
├─ scripts/                원본 → 앱 데이터로 바꾸는 도구 (Node)
│  ├─ config/              노선 조립 설정 (routes.json, lines.json)
│  ├─ lib/                 읽기·계산 로직
│  ├─ sources/             CSV / API 읽기
│  ├─ dev/                 계산 로직 테스트 (npm test)
│  └─ build-data.js        실행 진입점
├─ docs/                   설명 문서
├─ run.bat                 설치 + 앱 실행 (Windows)
├─ update-data.bat         CSV를 바꾼 뒤 노선 데이터 다시 만들기 (Windows)
└─ package.json, app.json, tsconfig.json, babel.config.js   프로젝트 설정
```

## 데이터가 흐르는 길
```
data-source/*.csv ──▶ scripts/ (build-data.js) ──▶ src/data/generated/*.json ──▶ 앱
 (사람이 넣음)        (섞인 형식을 읽고 코스별로 조립)    (자동 생성)
```
앱은 `src/data/generated` 만 읽어요. 원본이 CSV든 API든 앱 코드는 바뀌지 않아요.

## 탭과 폴더 이름 (같이 보기)
| 하단 탭 | 라우트 파일 | 실제 코드 |
|---|---|---|
| 홈 | `app/index.tsx` | `src/features/home/` |
| 노선도 | `app/lines.tsx` | `src/features/lines/LinesScreen.tsx` |
| (노선 상세, 탭 바 없음) | `app/line.tsx` | `src/features/lines/LineDetailScreen.tsx` |
| 도감 | `app/dex.tsx` | `src/features/dex/` |
| 설정 | `app/settings.tsx` | `src/features/settings/` |

## 어디를 고치면 되나요?
| 하고 싶은 일 | 파일 |
|---|---|
| 화면 문구·디자인 수정 | `src/features/<탭>/` |
| 하단 탭 이름·아이콘 | `app/_layout.tsx` |
| 보폭, 하루 목표 걸음 | `src/lib/progress.ts` (`STRIDE_M`, `DAILY_GOAL`) |
| 저장되는 값 추가·변경 | `src/store/useTrabby.ts` |
| 효과음·진동 | `src/shared/feedback.ts` (소리 파일은 `assets/sounds/`) |
| 하루 목표·연속 걷기 | `src/lib/progress.ts` (`DAILY_GOAL`), `src/lib/streak.ts` |
| 앱 아이콘·시작 화면 | `assets/icon.png`, `splash-icon.png` 등 + `app.json` |
| 캐릭터 그림 교체 | `assets/characters/<id>.png` 에 넣고 `run.bat` (자세한 규격: 그 폴더의 README) |
| 캐릭터 추가·해금 조건 (전 코스 완주) | `src/data/rewards.ts` (`CHARACTERS`) |
| 홈 배경 테마 (노선 컬러 테마는 자동 생성) | `src/features/settings/themes.ts` |
| 새 CSV 반영 | `data-source/` 에 넣고 `update-data.bat` |
| 역간 거리가 틀린 구간 고치기 | `data-source/fill.json` |
| 가지 노선(코스) 추가·수정 | `scripts/config/routes.json` |
| 이름 있는 노선(에버라인 등) 추가 | `scripts/config/lines.json` |
| 새 탭(화면) 추가 | `src/features/<이름>/` 만들고 `app/` 에 한 줄, `app/_layout.tsx` 에 탭 등록 |

## 지키는 규칙
1. `app/` 안 파일은 `export { default } from '...'` 한 줄만 둡니다. 코드는 `src/features/`에.
2. 한 탭의 코드는 그 탭 폴더 안에서 끝냅니다. 두 탭 이상이 쓰면 `shared/`나 `lib/`로 옮깁니다.
3. `src/data/generated/` 는 직접 고치지 않습니다. 원본(`data-source/`)이나 설정(`scripts/config/`)을 고치고 스크립트를 다시 실행합니다.
4. 노선도 탭·도감은 `src/data/index.ts` 의 `LINE_GROUPS`(같은 `group` 끼리 묶음)를 기준으로 그려요. 코스를 추가하면 `routes.json`에 `group`만 맞춰 주세요.
5. 노선 id: 1~9는 서울 노선(1호선은 경인선 코스), 11·12·13은 1호선 다른 코스, 21·22는 2호선 지선, 51은 5호선 마천지선, 100번대는 이름 있는 노선(에버라인=101).
