# 노선 데이터 갱신 가이드

## 평소 (CSV를 새로 받았을 때)
1. 새 CSV를 `data-source/` 에 넣습니다 (같은 노선이 두 파일에 있으면 에러로 알려줘요).
2. `update-data.bat` 더블클릭 (또는 `npm run build:data -- --all`).
3. 출력에서 노선별 역 개수와 ⚠ 표시를 확인합니다.

출력 예: `✓ 3호선: 44개 역, 총 57.4km (다음역…)`

## 메시지 읽는 법
| 메시지 | 뜻 | 할 일 |
|---|---|---|
| `✓ …` | 정상 생성 | 없음 |
| `⚠ 확인 필요: A→B …` | 두 열의 값이 앞 행과 달라서 한쪽을 골랐어요 | 실제 거리와 맞는지 확인, 틀리면 `fill.json` |
| `✗ … 거리를 못 읽은 구간 N곳` | 값이 비었거나 서로 안 맞아요 | 목록의 구간을 `fill.json` 에 추가 |
| `건너뜀: '○○' 노선은 … 등록해야` | 이름 있는 노선이라 id가 없어요 | `scripts/config/lines.json` 에 등록 |

## 틀린 거리 고치기 (`data-source/fill.json`)
```json
{ "1호선 경인선/청산→소요산": 5.8 }
```
형식: `"코스 이름/출발역→도착역": km`. 수동값이 CSV 값보다 우선해요.

## 파일 형식이 섞여 있어요 (data-source/subway.csv)
코레일 구간(다음 역 거리 + 앞 역 거리)과 서울교통공사 구간(앞 역 거리 + 누계)이 섞여 있고, 일부는 두 열이 뒤바뀌어 있어요.
`scripts/lib/resolve.js` 가 인접한 두 역의 값이 서로 맞는 해석을 고르고, 갈리면 이웃 구간의 방식을 따라가요.

## 노선(코스) 조립 설정 (`scripts/config/routes.json`)
파일이 조각나 있어서 코스마다 조각을 이어 붙이는 방법을 적어 둡니다.
- `label` 파일의 호선 칸 값 / `occ` 같은 값이 여러 번 나올 때 몇 번째 조각인지
- `from`, `to`, `count` 조각 안에서 쓸 구간
- `order` 파일 순서가 실제와 다를 때 올바른 순서 (8호선 별내선)
- `manual` 파일에 없는 역을 직접 입력 (5호선 방화~충정로)
- `join: "b4"` 가지 노선의 첫 구간은 그 행의 값을 그대로 사용
- `rename` 역 이름이 옛 이름일 때 바꾸기 (능길 → 신길온천)
- `kind` `main`(본선: 완주하면 노선 컬러 테마) / `extra`(추가 코스: 본선과 함께 한 노선의 전 코스에 포함 → 전부 완주하면 그 노선 캐릭터)
- `group` 같은 노선으로 묶을 이름. 노선도 탭에서 "1호선 > 경인선·경부선…" 처럼 묶여 보이고, 한 노선의 모든 코스를 완주하면 "전 코스" 뱃지를 줘요

## API로 받기 (인증키 필요)
`npm run fetch:data -- --all --url "<Open API 요청 URL>"`
CSV와 같은 결과 형식으로 만들어져요. (API 응답 형식은 실제 서버로는 확인하지 못했어요.)

## 데이터 점검 (`npm run check:data`)
`update-data.bat` 이 데이터를 만든 뒤 자동으로 실행해요. 기준값은 `scripts/config/expected.json` (확인된 총 길이·역 개수와 출처)이고, 새 코스를 확인하면 한 줄 추가하세요.

## 검증된 값
- 1호선 경인선: 광운대 55.1 / 청량리 60.6 / 서울역 68.4 / 용산 71.6 / 구로 80.1 / 인천 107.1 km (위키백과 누계와 일치)
- 5호선: 방화~하남검단산 52.9km = 본선 45.2 + 하남선 7.7
- 4호선: 진접~성신여대입구 누계가 위키백과와 모두 일치, 52개 역 순서가 공식 목록과 동일 (파일에 없던 풍양역 추가)
- 6호선 36.4km, 7호선 61.2km, 9호선 40.6km: 공식 노선 길이와 일치
- 8호선 별내선은 파일 값 대신 위키백과 공식 구간 거리 사용 (합계 30.1km 일치)
- 아직 기준이 없는 코스: 1호선 경부선·광명선·서동탄선, 2호선 지선 2개, 5호선 마천지선
