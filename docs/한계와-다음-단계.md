# 아직 안 된 것, 임시인 것

## 앱을 꺼 둔 동안의 걸음
- **iOS**: 앱을 다시 열 때 마지막으로 확인한 시각부터 지금까지의 걸음을 반영해요 (기기가 최근 7일을 기억). 구현했지만 실제 아이폰에서는 아직 확인하지 못했어요.
- **안드로이드**: 구현 전. 앱이 켜진 동안만 걸음을 세요. 이유: Expo 기본 걸음 센서(Pedometer)가 안드로이드에서는 지난 기록을 읽는 기능이 없어요.
- 안드로이드에서 하려면 **Health Connect** 연동이 필요해요.
  1. `react-native-health-connect` + 설정 플러그인 추가, `READ_STEPS` 권한
  2. Expo Go에서는 안 돌아서 **개발 빌드(EAS)** 로 확인해야 해요
  3. 앱을 열 때 `lastSeenAt` 이후 걸음을 읽어 `addSteps` 에 더해요 (usePedometer.ts 의 iOS 부분과 같은 자리)
  4. 다른 앱이 이미 기록한 걸음과 중복되지 않게 데이터 출처를 확인해야 해요

## 임시 자산 (교체하면 돼요)
| 자산 | 지금 | 교체 방법 |

| 앱 아이콘·시작 화면 | 코드로 그린 거북이 | `assets/icon.png`(1024, 불투명), `adaptive-icon.png`(1024, 투명·가운데 66% 안), `splash-icon.png`, `favicon.png` 를 같은 이름으로 교체 |

## 아직 실제 기기에서 확인하지 못한 것
- 걸음 센서 권한 흐름, 진동, 효과음, 시작 화면 설정(expo-splash-screen), iOS 꺼 둔 동안의 걸음
- 코스가 많은 노선(경부선 80개 역)의 스크롤 성능

## 출시 전에 필요한 것
- 개인정보 처리방침 (걸음 수는 기기 안에만 저장돼요 — 서버 전송 없음)
- 스토어용 개발 빌드(EAS), 앱 이름·설명·스크린샷
- 캐릭터 일러스트와 최종 아이콘
