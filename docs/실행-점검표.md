# 에뮬레이터 실행 점검표

`run.bat` 으로 앱을 띄운 뒤 위에서부터 차례로 확인하세요. 개발 모드에서는 홈 아래에 테스트 버튼 3개(+300 / +8,000 / +50,000 걸음)가 보여요.
(에뮬레이터에는 걸음 센서가 없어서 버튼으로 걸음을 넣어요.)

| # | 할 일 | 정상이면 |
|---|---|---|
| 1 | 앱 첫 실행 | 안내 3장 → "시작하기". 에뮬레이터는 "이 기기에서는 걸음 센서를 쓸 수 없어요" 노란 안내가 홈에 뜨는 게 정상 |
| 2 | 홈 확인 | 3호선 노선도, 거북이, 말풍선 "출발해볼까?", 카드에 "다음 주엽까지 N걸음" |
| 3 | `+300` 누르기 | 거북이가 통통 걷고 말풍선 "조금만 더!" → 2.5초 뒤 "쉬는 중" |
| 4 | `+300` 여러 번 (약 8번, 대화→주엽 약 2,300걸음) | "주엽역 도착!" 토스트 + 폴짝 + (소리·진동) |
| 5 | `+8,000` 누르기 | "오늘 목표 달성! 🔥 연속 1일" 토스트, 카드에 "🔥 연속 1일" |
| 6 | `+50,000` 두 번 (3호선 약 9.6만 걸음) | CLEAR 화면: 거북이 기쁨 자세, 보상(3호선 컬러 테마 + 뱃지), 팡파레 |
| 7 | "확인하기" | 다음 노선 고르는 시트가 올라옴 |
| 8 | 노선도 탭 | 노선별로 묶인 목록, 1호선 아래 코스 4개, 코스를 누르면 "바꿀까요?" 확인 |
| 9 | 도감 탭 | 노선 도감 / 캐릭터 도감(잠김은 흐리게) / 뱃지(연속 3·7·14·30일 포함) |
| 10 | 설정 탭 | 닉네임 변경, 알림·효과음·진동 켜고 끄기, 테마(3호선 컬러 열림), 언어, FAQ, 진행 초기화 |
| 11 | 앱을 완전히 끄고 다시 실행 | 진행도·완주 기록·설정이 그대로 (안내는 다시 안 나옴) |

## 에뮬레이터에서 다를 수 있는 것
- 진동은 안 느껴져요 (실기기에서 확인). 소리는 에뮬레이터 볼륨/설정에 따라 안 날 수 있어요.
- 이모지 모양은 기기마다 달라요.
- 앱을 꺼 둔 동안의 걸음 반영(iOS)은 실제 아이폰에서만 확인할 수 있어요.
