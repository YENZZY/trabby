# Trabby (트라비)

걸음 수로 지하철 노선 위를 걸어가며 노선을 도감처럼 수집하는 앱 (React Native + Expo).

## 실행 (Windows + Android Studio 에뮬레이터)
1. Android Studio에서 에뮬레이터를 먼저 켭니다.
2. `run.bat` 더블클릭 → 터미널에서 `a` 키.
3. 에뮬레이터에는 걸음 센서가 없어요. 홈 화면 하단 `+300 걸음 (DEV)` 버튼으로 테스트하세요.

## 명령어
| 명령 | 하는 일 |
|---|---|
| `run.bat` | 설치 + 앱 실행 |
| `update-data.bat` | 노선 데이터를 CSV에서 다시 만들고 점검 |
| `npm test` | 계산 로직(연속 걷기·걸음 저장소) 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run check:data` | 노선 데이터 점검 |
| `npm run build:assets` | 캐릭터 그림 연결 |

## 캐릭터 그림 바꾸기
`assets/characters/` 에 `tiger.png`(대기), `tiger_walk1.png`(걷기), `tiger_cheer.png`(도착·기쁨) 처럼 캐릭터 id + 상태 이름으로 그림을 넣고 `run.bat` 실행. 규격과 id 목록은 [assets/characters/README.md](assets/characters/README.md). 그림이 없는 캐릭터는 이모지로 보여요.

## 핵심 규칙
- **연속 걷기**: 하루 목표(8,000걸음)를 채운 날이 이어지면 "🔥 연속 N일". 3·7·14·30일 뱃지, 7일 연속이면 "불꽃" 테마.
- **알림·효과**: 역 도착, 목표 달성, 완주 때 토스트·효과음·진동 (설정에서 끌 수 있어요).
- 걸음은 **한 번에 한 노선(코스)** 에만 쌓입니다. 다른 노선으로 바꾸면 이전 진행도는 저장된 채 "일시정지".
- 노선에 역이 늘어나도 **완주 기록은 유지**되고, 새 구간만 이어서 걸을 수 있어요.
- **보상**: 노선(본선)을 완주하면 **그 노선 색 테마**. 코스가 여러 개인 노선(1호선 4개, 2호선 3개, 5호선 2개 코스)은 **전 코스를 완주**하면 **캐릭터**와 "전 코스" 뱃지. 앱의 **모든 코스**를 완주하면 **전설 캐릭터(용)**. 뱃지는 코스마다.
- 걸음 → 거리는 고정 보폭 60cm (`src/lib/progress.ts`).
