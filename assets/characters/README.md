# 캐릭터 그림 넣는 곳

그림 파일을 이 폴더에 넣고 `run.bat` 을 실행하면 앱에 반영돼요. 코드는 안 고쳐도 돼요.
그림이 없는 캐릭터·상태는 이모지/코드 움직임으로 보여요 — 하나씩 채워도 됩니다.

## 파일 이름 = 캐릭터 id + 상태
| 파일 이름 | 상태 | 언제 보여요 | 필수? |
|---|---|---|---|
| `tiger.png` | 대기 (기본) | 걸음이 멈춘 동안, 도감·프로필·노선 상세 | **필수** (이게 기본 그림) |
| `tiger_walk.png` | 걷는 중 | 걸음이 들어오는 동안(마지막 걸음 후 2.5초) | 선택 |
| `tiger_walk1.png`, `tiger_walk2.png` … | 걷는 중 (여러 장) | 번호 순서대로 0.22초마다 바꿔서 걷는 모션 | 선택 |
| `tiger_cheer.png` | 도착·기쁨 | 역을 지날 때 2.5초, CLEAR 화면, 보상 | 선택 |

- **기본 거북이(`turtle`)** 는 상태별 자세(서 있기·걷기 2자세·두 팔 들고 웃기)가 코드(SVG)로 이미 그려져 있어요. 그림 파일을 넣으면 그 그림이 우선해요.
- 상태 그림이 **없으면** 대기 그림을 쓰고, 걷는 중에는 코드로 통통 걷는 움직임, 도착에는 폴짝 뛰는 움직임을 줘요.
- 걷는 그림을 **2장 이상** 넣으면 코드 움직임 없이 프레임이 번갈아 나와요 (그림으로 걷는 모션을 직접 만들 때).

## 캐릭터 id
| id | 캐릭터 | 얻는 방법 |
|---|---|---|
| `turtle` | 기본 트라비 | 처음부터 |
| `tiger` | 호랑이 트라비 | 1호선 전 코스 완주 |
| `cat` | 고양이 트라비 | 2호선 전 코스 완주 |
| `bear` | 곰 트라비 | 5호선 전 코스 완주 |
| `dragon` | 전설의 용 트라비 | 모든 코스 완주 |

id 는 영문 소문자·숫자만 써요 (`_` 는 상태 구분용).
예: 호랑이 한 세트 = `tiger.png`, `tiger_walk1.png`, `tiger_walk2.png`, `tiger_cheer.png`

## 그림 규격
- **정사각형 512×512 이상, 배경 투명 PNG** (webp, jpg도 되지만 투명 PNG 추천)
- **한 장당 300KB 이하** (500KB를 넘으면 경고가 떠요)
- 캐릭터 둘레에 **여백 10% 정도**, 상태 그림끼리 **같은 크기·같은 위치**로 맞추세요 (바뀔 때 튀지 않게)
- 노선도 위에서는 **약 52px** 로 작게 보여요. 작게 줄여서도 알아볼 수 있는지 먼저 확인하세요.

## 새 캐릭터를 늘릴 때
1. `src/data/rewards.ts` 의 `CHARACTERS` 에 한 줄 추가 (id, 이름, 이모지, 해금 노선)
2. 같은 id 로 그림 파일 추가 (예: `rabbit.png`, `rabbit_walk1.png` …)
3. `run.bat`

## 그림을 AI로 만들 때
- 사용하는 도구의 **상업적 이용 조건**을 먼저 확인하세요.
- 기존 캐릭터·마스코트와 비슷하면 안 돼요.
- 캐릭터 5종과 상태 그림이 한 세트로 보이게 **같은 스타일**(외곽선 굵기, 색감, 표정)로 맞추세요.
- 그림을 만들기 전에 **캐릭터 시트 한 장**(정면·걷기 2장·기쁨)을 먼저 정해 두면 일관성이 좋아요.
